# TRMNL-DOCS Project

This project contains a local copy of the TRMNL framework documentation (version 3.1).

## Documentation
The documentation is stored in the `trmnl_docs/` directory. 

**IMPORTANT:** Always start by reading `trmnl_docs/INDEX.md`. This file contains a categorized table of contents and summaries for all available guides, which will help you identify the specific files needed for your task and minimize token usage.
